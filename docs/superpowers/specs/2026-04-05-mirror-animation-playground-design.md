# 镜面魔法动画 Playground 设计文档

## 背景

当前项目已经有：

- `mirror-agent`：本地摄像头、语音、多模态调试主链路
- `playgrounds/mirror-princess-demo`：镜面陪伴感方向的静态视觉 Demo

用户现在需要一个新的独立 Playground，用来一次性比较多组“黑底 + 粉色 + 细线条 + 魔法时刻”动画，好从中挑出若干个，用在不同场景里。

## 目标

创建一个新的独立页面，满足以下要求：

- 不改动现有 `mirror-agent` 调试页
- 单页直接展示 `15` 个动画
- 页面为黑底全屏总览，适合本机快速挑选
- 每个动画自动循环播放
- 整体气质细、轻、梦幻，接近“迪士尼魔法时刻”而不是厚重卡通贴纸
- 支持用户点击卡片进行多选，方便记录候选动画

## 非目标

- 本轮不接摄像头、麦克风或大模型状态
- 本轮不接 TTS、字幕或设备联动
- 本轮不引入外部动画库或构建工具

## 方案选择

### 方案 A：15 宫格总览页（采用）

特点：

- 一个页面直接看完 15 个动画
- 卡片统一尺寸和黑底舞台
- 默认自动循环

优点：

- 最适合横向比较气质差异
- 用户进入页面即可快速筛掉不喜欢的方向
- 实现简单，便于本地静态托管

缺点：

- 单个动画的沉浸感不如全屏展示

### 方案 B：单舞台轮播

优点：

- 单个动画更大，更适合看细节

缺点：

- 比较效率低
- 用户需要反复切换

### 方案 C：总览 + 大图联动

优点：

- 信息最完整

缺点：

- 页面复杂度更高
- 当前并不是必须

## 决策

采用方案 A：独立 15 宫格总览页。

## 页面结构

### 顶部说明区

- 页面标题
- 一句副标题，说明这是“镜面魔法动画 Playground”
- 说明可以点击卡片挑选多个候选动画

### 已选结果条

- 固定展示当前已选动画数量
- 展示当前已选动画名
- 用户点击卡片即可加入或移出结果条

### 动画宫格

- 桌面端优先展示为多列网格
- 移动端自动变为更窄列数
- 每张卡片包含：
  - 动画舞台
  - 动画名称
  - 一句风格标签
  - 场景标签

## 动画分组

15 个动画分为三组：

### 1. 桃心线稿组

- 细线桃心绽放
- 双线桃心回声
- 单笔勾心
- 桃心呼吸光
- 桃心碎光散落

### 2. 星屑魔法组

- 星点聚拢成心
- 魔法棒扫光
- 彗尾绕心
- 光环涟漪
- 星屑旋涡

### 3. 公主符号组

- 蝴蝶结闪现
- 皇冠描边
- 珍珠轨迹
- 丝带回旋
- 许愿光晕

## 视觉原则

- 舞台统一为深黑到墨灰的层次背景
- 主色为粉色，辅色仅允许少量白金星屑
- 线条尽量细，减少厚重描边
- 发光要柔和，不做大面积强闪
- 页面整体不出现大段说明文字，重点是看效果

## 技术方案

新增独立目录：

- `playgrounds/mirror-animation-playground/index.html`
- `playgrounds/mirror-animation-playground/style.css`
- `playgrounds/mirror-animation-playground/app.js`

实现方式：

- 纯 HTML + CSS + 原生 JS
- JS 维护 `15` 个动画的元数据
- CSS 提供黑底舞台、统一卡片布局和每种动画的关键帧
- 页面加载后由 JS 渲染宫格和多选交互

## 测试策略

新增轻量静态契约测试，覆盖：

- 新页面文件存在
- 页面包含动画宫格容器和已选结果条
- JS 动画数据条目数为 `15`
- JS 包含多选记录逻辑

## 交付结果

交付一个本地可直接访问的独立 URL，用户打开后即可横向比较并挑选多个候选动画。
